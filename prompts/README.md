# Prompts por fases

Cada prompt corresponde a una fase del `ROADMAP.md`. No se ejecutan todos a la vez: cada fase parte de los resultados y decisiones aprobados en la anterior.

| Orden | Archivo | Objetivo |
|---|---|---|
| 00 | `00_INVESTIGACION_Y_DISENO.md` | Investigar, definir el producto y validar tecnología. |
| 01 | `01_FUNDACION_APLICACION.md` | Crear la aplicación de escritorio y la base del proyecto. |
| 02 | `02_LIENZO_Y_DIBUJO.md` | Implementar el lienzo, herramientas y capas. |
| 03 | `03_MODO_GUIADO_Y_BIBLIOTECA.md` | Crear biblioteca y ayudas editables. |
| 04 | `04_ANIMACION_Y_LINEA_DE_TIEMPO.md` | Animación de trazos, objetos y fotogramas. |
| 05 | `05_AUDIO_Y_NARRACION.md` | Importación y edición básica de audio. |
| 06 | `06_RENDERIZADO_Y_EXPORTACION.md` | Generar vídeo final y sincronizar audio. |
| 07 | `07_CALIDAD_RENDIMIENTO_Y_ACCESIBILIDAD.md` | Estabilización y experiencia de usuario. |
| 08 | `08_PREPARACION_DE_LANZAMIENTO.md` | Empaquetado, documentación y release. |
| 09 | `09_MANTENIMIENTO_Y_CAMBIOS.md` | Gestionar cambios futuros y regresiones. |
| 10 | `10_PLANTILLA_DE_TAREA.md` | Plantilla para nuevas funcionalidades o correcciones. |

El prompt 00 se ejecuta en Plan Mode y su resultado (arquitectura y decisiones) debe aprobarse antes de empezar el 01.
