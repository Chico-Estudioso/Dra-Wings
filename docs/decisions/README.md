# Decisiones de arquitectura (ADR)

Crear un archivo `ADR-NNN-titulo.md` para decisiones que afecten a varios módulos, formato del proyecto, tecnologías principales o compatibilidad a largo plazo.

Plantilla mínima:

- Estado: Propuesta / Aprobada / Rechazada / Sustituida.
- Fecha.
- Contexto y problema.
- Opciones consideradas.
- Decisión.
- Consecuencias positivas y negativas.
- Pruebas o referencias que respaldan la decisión.
